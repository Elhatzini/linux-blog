SSH: Ασφαλής απομακρυσμένη πρόσβαση

Σύνδεση, μεταφορά αρχείων και authentication με SSH.

Σύνδεση

Η βασική σύνταξη είναι user@host.

ssh user@192.168.1.20

💡 Τι περιμένουμε: Στην πρώτη σύνδεση έλεγξε προσεκτικά το host fingerprint.

Έλεγχος SSH server

Στον server έλεγξε την υπηρεσία.

sudo systemctl status ssh
ss -lntp | grep ':22'

💡 Τι περιμένουμε: Η θύρα μπορεί να έχει αλλάξει από την προεπιλεγμένη 22.

scp

Μετέφερε αρχείο μέσω SSH.

scp report.txt user@192.168.1.20:/home/user/

💡 Τι περιμένουμε: Για μεγάλες ή επαναλαμβανόμενες μεταφορές, εξέτασε rsync over SSH.

SSH keys

Δημιούργησε key pair και εγκατέστησε το public key.

ssh-keygen -t ed25519
ssh-copy-id user@192.168.1.20

💡 Τι περιμένουμε: Μην μοιράζεσαι το private key.

Troubleshooting

Έλεγξε DNS/IP, route, listening port και firewall.

ping 192.168.1.20
nc -vz 192.168.1.20 22
ssh -vv user@192.168.1.20

💡 Τι περιμένουμε: Το ssh -vv παρέχει αναλυτικές πληροφορίες σύνδεσης.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

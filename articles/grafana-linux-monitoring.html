Grafana για Linux Monitoring

Οργάνωσε τα metrics του Linux server σε dashboards που βοηθούν στο troubleshooting.

Datasource

Σύνδεσε το Grafana με τον Prometheus ως data source.

# URL παράδειγμα
http://prometheus:9090

💡 Τι περιμένουμε: Το ακριβές URL εξαρτάται από την εγκατάστασή σου.

CPU panel

Ένα συνηθισμένο metric είναι το CPU time. Με rate και aggregation δημιουργείς χρήσιμες μετρήσεις.

rate(node_cpu_seconds_total[5m])

💡 Τι περιμένουμε: Οι τελικές PromQL εκφράσεις εξαρτώνται από το dashboard και τα labels.

Memory panel

Παρακολούθησε available memory και συνολική μνήμη.

node_memory_MemAvailable_bytes
node_memory_MemTotal_bytes

💡 Τι περιμένουμε: Μετέτρεψε bytes σε GB μέσα από τις μονάδες του panel.

Disk panel

Παρακολούθησε διαθέσιμο filesystem space.

node_filesystem_avail_bytes

💡 Τι περιμένουμε: Φίλτραρε pseudo-filesystems ώστε το dashboard να παραμένει καθαρό.

Alerts

Δημιούργησε alerts για πραγματικές ανάγκες, όχι για κάθε μικρή μεταβολή.

# Παράδειγμα λογικής
# filesystem free < 15%

💡 Τι περιμένουμε: Βάλε κατάλληλα thresholds και διάστημα αξιολόγησης ώστε να αποφεύγονται false positives.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

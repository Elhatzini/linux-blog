Linux Permissions: chmod, chown και chgrp

Κατανόησε τα rwx permissions και μάθε να διορθώνεις συνηθισμένα permission problems.

Τα τρία επίπεδα

Τα permissions χωρίζονται σε owner, group και others. Κάθε επίπεδο μπορεί να έχει read, write και execute.

ls -l script.sh
# -rwxr-xr--

💡 Τι περιμένουμε: Το r=4, w=2 και x=1 χρησιμοποιούνται στη συμβολική/αριθμητική αναπαράσταση.

chmod με αριθμούς

Το 755 σημαίνει rwx για owner και r-x για group/others.

chmod 755 script.sh
ls -l script.sh

💡 Τι περιμένουμε: Χρησιμοποίησε αριθμητικά permissions όταν γνωρίζεις ακριβώς το αποτέλεσμα που θέλεις.

chmod συμβολικά

Μπορείς να προσθέσεις ή να αφαιρέσεις συγκεκριμένο permission.

chmod u+x script.sh
chmod g-w file.txt

💡 Τι περιμένουμε: Η συμβολική μορφή είναι συχνά πιο ξεκάθαρη για μικρές αλλαγές.

chown

Αλλάζει owner και, προαιρετικά, group.

sudo chown user:users file.txt

💡 Τι περιμένουμε: Έλεγξε πρώτα τον σωστό username και group.

chgrp

Αλλάζει μόνο το group ownership.

sudo chgrp developers project.txt

💡 Τι περιμένουμε: Ο χρήστης πρέπει να έχει τα κατάλληλα δικαιώματα.

Troubleshooting

Αν μια εφαρμογή δεν μπορεί να διαβάσει αρχείο, έλεγξε permissions και ownership πριν αλλάξεις τυχαία δικαιώματα.

ls -l file.txt
namei -l /path/to/file.txt

💡 Τι περιμένουμε: Μην χρησιμοποιείς chmod -R 777 ως γενική λύση.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

if, for και while στο Bash

Μάθε τις βασικές δομές ελέγχου που μετατρέπουν απλές εντολές σε αυτοματισμούς.

if

Έλεγξε αν υπάρχει ένα αρχείο.

if [ -f /etc/hostname ]; then
  echo "Υπάρχει"
else
  echo "Δεν υπάρχει"
fi

💡 Τι περιμένουμε: Χρησιμοποίησε -f για κανονικό αρχείο και -d για directory.

for

Επανάλαβε μια ενέργεια για πολλά αρχεία.

for file in *.log; do
  echo "$file"
done

💡 Τι περιμένουμε: Τα quotes γύρω από το variable βοηθούν όταν filenames περιέχουν spaces.

while

Εκτέλεσε επαναληπτικά μια ενέργεια όσο ισχύει μια συνθήκη.

COUNT=1
while [ $COUNT -le 5 ]; do
  echo $COUNT
  COUNT=$((COUNT+1))
done

💡 Τι περιμένουμε: Πρόσεξε να υπάρχει συνθήκη που κάποτε γίνεται false.

Πρακτική άσκηση

Γράψε script που εμφανίζει όλα τα .log αρχεία ενός φακέλου και αναφέρει αν είναι άδεια.

for f in /var/log/*.log; do
  [ -f "$f" ] && echo "$f"
done

💡 Τι περιμένουμε: Δοκίμασε πρώτα σε δικό σου test directory.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

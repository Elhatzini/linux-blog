Bash Variables και βασική σύνταξη

Ξεκίνα να γράφεις Bash scripts με μεταβλητές, arguments και exit codes.

Shebang

Ένα script συνήθως ξεκινά με shebang που δηλώνει τον interpreter.

#!/bin/bash

echo "Hello Linux"

💡 Τι περιμένουμε: Κάνε το αρχείο executable με chmod.

Variables

Ανάθεσε τιμή χωρίς κενά γύρω από το =.

NAME="Linux"
echo "Hello $NAME"

💡 Τι περιμένουμε: Χρησιμοποίησε quotes όταν η τιμή μπορεί να περιέχει spaces.

Arguments

Τα $1, $2 είναι arguments που δόθηκαν στο script.

#!/bin/bash
echo "Πρώτο argument: $1"

# ./script.sh backup

💡 Τι περιμένουμε: Το $# δείχνει πόσα arguments δόθηκαν.

Exit code

Το $? δείχνει τον κωδικό εξόδου της τελευταίας εντολής.

mkdir /tmp/test
 echo $?

💡 Τι περιμένουμε: Συνήθως 0 σημαίνει επιτυχία, ενώ μη μηδενική τιμή δηλώνει σφάλμα.

Καλή πρακτική

Χρησιμοποίησε set -euo pipefail σε scripts όπου ταιριάζει και έλεγχε τις κρίσιμες εντολές.

#!/bin/bash
set -euo pipefail

💡 Τι περιμένουμε: Δοκίμαζε πάντα scripts πρώτα σε test directory.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

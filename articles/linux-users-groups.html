Users και Groups στο Linux

Δημιούργησε χρήστες, ομάδες και δικαιώματα πρόσβασης με ασφαλή τρόπο.

Δημιουργία χρήστη

Σε σύγχρονα distributions μπορείς να χρησιμοποιήσεις adduser για διαδραστική δημιουργία χρήστη.

sudo adduser maria

💡 Τι περιμένουμε: Ακολούθησε τις ερωτήσεις για password και βασικά στοιχεία.

Έλεγχος χρήστη

Χρησιμοποίησε id και groups.

id maria
groups maria

💡 Τι περιμένουμε: Έτσι βλέπεις UID, GID και memberships.

Groups

Δημιούργησε μια ομάδα και πρόσθεσε χρήστη.

sudo groupadd developers
sudo usermod -aG developers maria

💡 Τι περιμένουμε: Το -aG είναι σημαντικό: το -G χωρίς -a μπορεί να αντικαταστήσει υπάρχοντα supplementary groups.

Password

Άλλαξε password με passwd.

sudo passwd maria

💡 Τι περιμένουμε: Για policy και λήξη password χρησιμοποίησε τα εργαλεία του distribution.

Διαγραφή

Διέγραψε χρήστη όταν χρειάζεται και αποφάσισε αν θέλεις να κρατήσεις το home directory.

sudo userdel maria

💡 Τι περιμένουμε: Μην διαγράφεις λογαριασμό χωρίς να ελέγξεις πρώτα αν έχει ownership σημαντικών αρχείων.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

Βασικές εντολές δικτύου Linux

Ένα πρακτικό checklist για IP, routes, ports και connectivity.

IP configuration

Δες interfaces και IP addresses.

ip addr

💡 Τι περιμένουμε: Αναζήτησε το interface που έχει την ενεργή σύνδεση.

Routing

Δες το routing table και default gateway.

ip route

💡 Τι περιμένουμε: Αν λείπει default route, η πρόσβαση εκτός τοπικού δικτύου μπορεί να αποτύχει.

Connectivity

Έλεγξε αρχικά gateway και μετά έναν γνωστό εξωτερικό host.

ping -c 4 192.168.1.1
ping -c 4 1.1.1.1

💡 Τι περιμένουμε: Αποτυχία στο δεύτερο αλλά επιτυχία στο πρώτο δείχνει διαφορετική κατηγορία προβλήματος από DNS.

Ports

Δες listening TCP/UDP sockets.

ss -lntup

💡 Τι περιμένουμε: Χρήσιμο όταν μια υπηρεσία φαίνεται να τρέχει αλλά δεν δέχεται συνδέσεις.

DNS

Έλεγξε resolution.

resolvectl status
getent hosts example.com

💡 Τι περιμένουμε: Αν η IP λειτουργεί αλλά το hostname όχι, εξέτασε DNS.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

10 βασικές εντολές Linux που πρέπει να γνωρίζεις

Οι 10 εντολές που θα χρησιμοποιείς ξανά και ξανά σε Linux desktop και server.

1. pwd — Πού βρίσκομαι;

Η pwd εμφανίζει το πλήρες path του τρέχοντος φακέλου.

pwd

💡 Τι περιμένουμε: Το αποτέλεσμα μπορεί να είναι /home/user.

2. ls — Τι υπάρχει εδώ;

Με την ls βλέπουμε αρχεία και φακέλους. Για περισσότερες πληροφορίες χρησιμοποιούμε -l και για hidden files -a.

ls -lah

💡 Τι περιμένουμε: Θα δεις permissions, owner, μέγεθος και ημερομηνία τροποποίησης.

3. cd — Μετακίνηση

Η cd αλλάζει τον τρέχοντα φάκελο.

cd /var/log
pwd
cd ~

💡 Τι περιμένουμε: Το ~ σε μεταφέρει στο home directory του χρήστη.

4. mkdir — Δημιουργία φακέλου

Δημιούργησε έναν νέο φάκελο με mkdir. Με -p δημιουργείς και τα ενδιάμεσα directories.

mkdir -p ~/linux-lab/test

💡 Τι περιμένουμε: Ο φάκελος linux-lab/test δημιουργείται χωρίς να χρειάζεται να υπάρχει πρώτα το linux-lab.

5. cp — Αντιγραφή

Η cp αντιγράφει αρχεία. Για φακέλους χρειάζεται συνήθως -r.

cp file.txt file-backup.txt
cp -r project project-backup

💡 Τι περιμένουμε: Έλεγξε με ls -l ότι δημιουργήθηκε το αντίγραφο.

6. mv — Μετακίνηση ή μετονομασία

Η mv χρησιμοποιείται τόσο για μετακίνηση όσο και για rename.

mv old.txt new.txt
mv new.txt ~/Documents/

💡 Τι περιμένουμε: Η ίδια εντολή μπορεί να αλλάξει όνομα ή θέση ενός αρχείου.

7. rm — Διαγραφή

Η rm διαγράφει αρχεία. Το -r χρησιμοποιείται για directories. Χρειάζεται ιδιαίτερη προσοχή.

rm test.txt
rm -r test-folder

💡 Τι περιμένουμε: Η διαγραφή από το shell δεν λειτουργεί σαν Recycle Bin. Έλεγξε την εντολή πριν πατήσεις Enter.

8. cat — Προβολή αρχείου

Η cat εμφανίζει το περιεχόμενο ενός μικρού αρχείου.

cat /etc/hostname

💡 Τι περιμένουμε: Για μεγάλα αρχεία προτίμησε less, ώστε να τα βλέπεις σελίδα-σελίδα.

9. grep — Αναζήτηση κειμένου

Η grep βρίσκει γραμμές που περιέχουν ένα μοτίβο.

grep -i "error" /var/log/syslog

💡 Τι περιμένουμε: Το -i αγνοεί πεζά/κεφαλαία. Σε ορισμένα συστήματα το syslog μπορεί να βρίσκεται αλλού ή να απαιτεί δικαιώματα.

10. sudo — Εκτέλεση με δικαιώματα διαχειριστή

Το sudo εκτελεί μια εντολή με δικαιώματα administrator, σύμφωνα με την πολιτική του συστήματος.

sudo systemctl status ssh

💡 Τι περιμένουμε: Αν ο χρήστης δεν έχει δικαίωμα sudo, θα χρειαστεί αλλαγή των σχετικών δικαιωμάτων.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

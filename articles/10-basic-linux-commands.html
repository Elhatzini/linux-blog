10 βασικές εντολές Linux που πρέπει να γνωρίζεις

Ένα πρακτικό ξεκίνημα με τις εντολές που χρησιμοποιούμε καθημερινά.

1. pwd — Πού βρίσκομαι;

Εμφανίζει τον τρέχοντα φάκελο εργασίας.

pwd

2. ls — Τι υπάρχει στον φάκελο;

ls -lah

Το -l δείχνει λεπτομέρειες και το -a περιλαμβάνει hidden files.

3. cd — Μετακίνηση

cd /var/log
cd ..
cd ~

4. cp και 5. mv

cp file.txt backup.txt
mv old.txt new.txt

6. mkdir και 7. rm

mkdir projects
rm file.txt
rm -r old-folder

8. cat

cat /etc/hostname

9. grep

grep "error" /var/log/syslog

10. sudo

sudo systemctl restart ssh

Το sudo εκτελεί μια εντολή με δικαιώματα διαχειριστή, σύμφωνα με την πολιτική του συστήματος.

Εγκατάσταση Ubuntu Server βήμα-βήμα

Ένας ασφαλής οδηγός για να στήσεις το πρώτο σου Ubuntu Server σε φυσικό ή εικονικό μηχάνημα.

1. Προετοιμασία

Κατέβασε το επίσημο ISO της έκδοσης Ubuntu Server που θα χρησιμοποιήσεις και έλεγξε τις απαιτήσεις του μηχανήματος ή της VM.

# Παράδειγμα σε VM
# 2 CPU cores
# 4 GB RAM
# 25+ GB disk

💡 Τι περιμένουμε: Για production εγκατάσταση, σχεδίασε storage, backups και networking πριν ξεκινήσεις.

2. Δίκτυο

Κατά την εγκατάσταση επίλεξε σωστό interface και, όπου χρειάζεται, στατική IP σύμφωνα με το δίκτυό σου.

ip addr
ip route

💡 Τι περιμένουμε: Μετά την εγκατάσταση επιβεβαίωσε IP, gateway και DNS.

3. Χρήστης

Δημιούργησε έναν κανονικό χρήστη και χρησιμοποίησε sudo αντί να δουλεύεις συνεχώς ως root.

whoami
id

💡 Τι περιμένουμε: Ο κανονικός χρήστης με sudo είναι ασφαλέστερη καθημερινή πρακτική.

4. Ενημέρωση

Μετά το πρώτο boot, κάνε update και upgrade.

sudo apt update
sudo apt upgrade

💡 Τι περιμένουμε: Αν υπάρχουν kernel updates, μπορεί να χρειαστεί reboot.

5. SSH

Εγκατάστησε OpenSSH Server όταν χρειάζεσαι απομακρυσμένη διαχείριση.

sudo apt install openssh-server
sudo systemctl status ssh

💡 Τι περιμένουμε: Πριν κλείσεις την τοπική κονσόλα, επιβεβαίωσε ότι μπορείς να συνδεθείς μέσω SSH.

6. Βασικός έλεγχος

Έλεγξε hostname, IP, disk και memory.

hostnamectl
ip addr
df -h
free -h

💡 Τι περιμένουμε: Κράτησε αυτές τις εντολές ως πρώτο checklist μετά την εγκατάσταση.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

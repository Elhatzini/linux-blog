UFW Firewall στο Ubuntu

Βασικές ρυθμίσεις firewall με UFW χωρίς να κλειδώσεις κατά λάθος το SSH.

Προσοχή στο SSH

Αν είσαι συνδεδεμένος απομακρυσμένα, επίτρεψε πρώτα το SSH πριν ενεργοποιήσεις firewall.

sudo ufw allow OpenSSH

💡 Τι περιμένουμε: Κράτησε ανοιχτή μια ενεργή σύνδεση μέχρι να επιβεβαιώσεις ότι όλα λειτουργούν.

Ενεργοποίηση

Δες πρώτα την κατάσταση και μετά ενεργοποίησε.

sudo ufw status verbose
sudo ufw enable

💡 Τι περιμένουμε: Το firewall εφαρμόζει τους κανόνες που έχεις ορίσει.

Allow / deny

Άνοιξε μόνο τις υπηρεσίες που χρειάζονται.

sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw deny 23/tcp

💡 Τι περιμένουμε: Απόφυγε να ανοίγεις θύρες χωρίς λόγο.

Διαγραφή rule

Δες numbered rules και αφαίρεσε λανθασμένο rule.

sudo ufw status numbered
sudo ufw delete 3

💡 Τι περιμένουμε: Ο αριθμός εξαρτάται από την τρέχουσα λίστα.

Logs

Ενεργοποίησε logging όταν χρειάζεται troubleshooting.

sudo ufw logging on

💡 Τι περιμένουμε: Μην αφήνεις περιττό verbose logging για πάντα χωρίς λόγο.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

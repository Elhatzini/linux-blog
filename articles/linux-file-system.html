Η δομή αρχείων στο Linux

Μάθε τι σημαίνουν οι βασικοί κατάλογοι ενός Linux συστήματος και πού πρέπει να ψάχνεις.

/ — Η ρίζα του συστήματος

Όλα τα paths ξεκινούν από το root directory /. Δεν είναι το ίδιο με το /root, που είναι το home του root user.

ls -lah /

💡 Τι περιμένουμε: Θα δεις τους βασικούς καταλόγους του συστήματος.

/home — Τα δεδομένα των χρηστών

Συνήθως κάθε κανονικός χρήστης έχει έναν φάκελο μέσα στο /home.

ls -lah /home

💡 Τι περιμένουμε: Τα προσωπικά αρχεία του χρήστη βρίσκονται συνήθως εδώ.

/etc — Ρυθμίσεις

Πολλά system-wide configuration files βρίσκονται στο /etc.

ls /etc
cat /etc/hostname

💡 Τι περιμένουμε: Μην τροποποιείς αρχεία του /etc χωρίς να γνωρίζεις τη μορφή και τον σκοπό τους.

/var — Μεταβαλλόμενα δεδομένα

Logs, caches και άλλα δεδομένα που αλλάζουν κατά τη λειτουργία βρίσκονται συχνά στο /var.

sudo du -sh /var/*

💡 Τι περιμένουμε: Χρήσιμο σημείο ελέγχου όταν ο δίσκος γεμίζει.

/tmp — Προσωρινά αρχεία

Χρησιμοποιείται για προσωρινά δεδομένα εφαρμογών και διαδικασιών.

ls -lah /tmp

💡 Τι περιμένουμε: Μην θεωρείς το /tmp κατάλληλο για μόνιμη αποθήκευση.

/usr — Εφαρμογές και βιβλιοθήκες

Περιέχει μεγάλο μέρος των εγκατεστημένων προγραμμάτων, βιβλιοθηκών και shared data.

ls /usr/bin | head

💡 Τι περιμένουμε: Οι ακριβείς λεπτομέρειες διαφέρουν ανά distribution.

/dev — Συσκευές

Το Linux παρουσιάζει πολλές συσκευές ως device files μέσα στο /dev.

ls -l /dev | head

💡 Τι περιμένουμε: Παράδειγμα: δίσκοι, terminals και pseudo-devices.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

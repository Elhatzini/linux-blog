DNS Troubleshooting στο Linux

Μάθε να ξεχωρίζεις DNS πρόβλημα από πρόβλημα δικτύου.

1. Έλεγξε connectivity

Πριν κατηγορήσεις το DNS, έλεγξε αν υπάρχει γενικά δικτυακή σύνδεση.

ip route
ping -c 3 1.1.1.1

💡 Τι περιμένουμε: Αν ούτε IP connectivity λειτουργεί, το πρόβλημα μπορεί να είναι route, gateway ή firewall.

2. Έλεγξε resolver

Σε συστήματα με systemd-resolved, δες την κατάσταση.

resolvectl status

💡 Τι περιμένουμε: Έλεγξε ποιο DNS server χρησιμοποιείται.

3. Query

Κάνε lookup με dig όπου είναι εγκατεστημένο.

dig example.com
nslookup example.com

💡 Τι περιμένουμε: Σύγκρινε διαφορετικούς resolvers όταν χρειάζεται.

4. hosts

Το local hosts file μπορεί να επηρεάσει resolution.

cat /etc/hosts

💡 Τι περιμένουμε: Έλεγξε για λανθασμένες ή παλιές εγγραφές.

5. Cache

Αν χρησιμοποιείται systemd-resolved, μπορείς να κάνεις flush cache.

sudo resolvectl flush-caches

💡 Τι περιμένουμε: Μετά επανάλαβε το query.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

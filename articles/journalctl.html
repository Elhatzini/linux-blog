journalctl: Διάβασμα Linux logs

Χρησιμοποίησε το systemd journal για να βρεις τι συνέβη σε μια υπηρεσία ή στο σύστημα.

Όλα τα logs

Η journalctl εμφανίζει καταχωρήσεις του journal.

journalctl --no-pager | tail -50

💡 Τι περιμένουμε: Για μεγάλη έξοδο προτίμησε φίλτρα αντί να εμφανίζεις ολόκληρο το journal.

Logs υπηρεσίας

Φίλτραρε με -u.

journalctl -u ssh --no-pager

💡 Τι περιμένουμε: Αντικατάστησε ssh με το όνομα της υπηρεσίας.

Παρακολούθηση σε πραγματικό χρόνο

Με -f βλέπεις νέα entries καθώς δημιουργούνται.

sudo journalctl -u ssh -f

💡 Τι περιμένουμε: Πάτησε Ctrl+C για έξοδο.

Χρονικό φίλτρο

Περιορισμός σε συγκεκριμένο χρονικό διάστημα.

journalctl --since "1 hour ago"
journalctl --since today

💡 Τι περιμένουμε: Χρήσιμο μετά από restart ή εμφάνιση προβλήματος.

Kernel messages

Για kernel-related θέματα μπορείς να χρησιμοποιήσεις -k.

journalctl -k -b

💡 Τι περιμένουμε: Το -b περιορίζει στο τρέχον boot.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

systemctl: Διαχείριση υπηρεσιών Linux

Μάθε να διαχειρίζεσαι services με systemd και να εντοπίζεις failed υπηρεσίες.

Status

Ο έλεγχος status είναι το πρώτο βήμα όταν μια υπηρεσία δεν λειτουργεί.

systemctl status ssh

💡 Τι περιμένουμε: Δες αν είναι active, inactive ή failed και διάβασε τα τελευταία log messages.

Start, stop, restart

Χρησιμοποίησε start/stop/restart ανάλογα με την ανάγκη.

sudo systemctl start ssh
sudo systemctl stop ssh
sudo systemctl restart ssh

💡 Τι περιμένουμε: Πρόσεχε το stop σε remote server γιατί μπορεί να χάσεις τη σύνδεσή σου.

Enable και disable

Το enable αφορά την εκκίνηση κατά το boot.

sudo systemctl enable ssh
sudo systemctl disable ssh

💡 Τι περιμένουμε: Το enable δεν σημαίνει ότι η υπηρεσία ξεκινά απαραίτητα εκείνη τη στιγμή.

Failed services

Βρες services που απέτυχαν.

systemctl --failed

💡 Τι περιμένουμε: Στη συνέχεια χρησιμοποίησε status και journalctl για την αιτία.

Logs

Δες τα logs μιας συγκεκριμένης υπηρεσίας.

journalctl -u ssh --since today

💡 Τι περιμένουμε: Συνδύασε systemctl και journalctl για αποτελεσματικό troubleshooting.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

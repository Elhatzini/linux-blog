Αυτόματο Backup με Bash και rsync

Φτιάξε ένα απλό backup script και πρόσθεσε logging και ασφαλείς ελέγχους.

1. Προετοιμασία

Ορίζουμε source και destination. Για πραγματικό backup προτίμησε διαφορετικό δίσκο ή σύστημα.

SOURCE="/home/user/data/"
DEST="/backup/data/"

💡 Τι περιμένουμε: Έλεγξε ότι τα paths είναι σωστά πριν χρησιμοποιήσεις --delete.

2. rsync

Το rsync αντιγράφει μόνο τις απαραίτητες αλλαγές.

rsync -av "$SOURCE" "$DEST"

💡 Τι περιμένουμε: Το -a διατηρεί βασικά attributes και το -v εμφανίζει πληροφορίες.

3. Logging

Κατέγραψε ημερομηνία και έξοδο σε log.

LOG="/var/log/mybackup.log"
rsync -av "$SOURCE" "$DEST" >> "$LOG" 2>&1

💡 Τι περιμένουμε: Για log σε /var/log πιθανόν χρειάζεσαι κατάλληλα permissions.

4. --delete

Διατηρεί τον προορισμό ίδιο με την πηγή, διαγράφοντας παλιά αρχεία από destination.

rsync -av --delete "$SOURCE" "$DEST"

💡 Τι περιμένουμε: Πολύ ισχυρή επιλογή: δοκίμασέ την πρώτα με --dry-run.

5. Dry run

Προσομοίωσε το backup χωρίς αλλαγές.

rsync -av --dry-run --delete "$SOURCE" "$DEST"

💡 Τι περιμένουμε: Έλεγξε την έξοδο πριν ενεργοποιήσεις το πραγματικό backup.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

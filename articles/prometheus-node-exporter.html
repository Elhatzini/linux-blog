Prometheus και Node Exporter

Κατανόησε πώς συλλέγονται Linux metrics και πώς φτάνουν στο Prometheus.

Τι είναι ο Node Exporter;

Ο Node Exporter εκθέτει metrics του Linux host, όπως CPU, memory, filesystem και network.

curl http://localhost:9100/metrics | head

💡 Τι περιμένουμε: Η θύρα 9100 είναι συνηθισμένη προεπιλογή.

Prometheus

Το Prometheus κάνει scrape τα metrics σε χρονικά διαστήματα.

# Παράδειγμα scrape target
- targets: ['192.168.1.20:9100']

💡 Τι περιμένουμε: Περιορίστε την πρόσβαση στη θύρα metrics στο monitoring network.

Έλεγχος

Βεβαιώσου ότι το target είναι reachable από τον Prometheus server.

curl http://192.168.1.20:9100/metrics

💡 Τι περιμένουμε: Αν δεν υπάρχει απάντηση, έλεγξε service, listening port και firewall.

Metrics

Αναζήτησε ενδεικτικά metrics για CPU και filesystem.

node_cpu_seconds_total
node_filesystem_avail_bytes

💡 Τι περιμένουμε: Στην πράξη χρησιμοποιείς PromQL για aggregations και rates.

Ασφάλεια

Μην εκθέτεις monitoring endpoints δημόσια χωρίς λόγο.

ss -lntp | grep 9100

💡 Τι περιμένουμε: Χρησιμοποίησε firewall και κατάλληλο network segmentation.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.

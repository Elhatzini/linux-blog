5 βασικά βήματα για ασφαλές SSH

Πρακτικές κινήσεις για πιο ελεγχόμενη πρόσβαση SSH σε Linux server.

1. Updates

Κράτα το λειτουργικό και OpenSSH ενημερωμένα.

sudo apt update
sudo apt upgrade

💡 Τι περιμένουμε: Οι ενημερώσεις ασφαλείας είναι βασικό μέρος της διαχείρισης server.

2. SSH keys

Χρησιμοποίησε public-key authentication όπου είναι κατάλληλο.

ssh-keygen -t ed25519
ssh-copy-id user@server

💡 Τι περιμένουμε: Προστάτευσε το private key και χρησιμοποίησε passphrase.

3. Περιορισμός πρόσβασης

Χρησιμοποίησε firewall και, όπου χρειάζεται, AllowUsers/AllowGroups στο sshd configuration.

sudo ufw allow from 192.168.1.0/24 to any port 22 proto tcp

💡 Τι περιμένουμε: Προσαρμόζεις το subnet στο πραγματικό σου δίκτυο.

4. Έλεγχος logs

Παρακολούθησε αποτυχημένες προσπάθειες σύνδεσης.

sudo journalctl -u ssh --since today

💡 Τι περιμένουμε: Μην βασίζεσαι μόνο σε αλλαγή port ως μέτρο ασφάλειας.

5. Έλεγχος configuration

Πριν κάνεις restart SSH, έλεγξε τη σύνταξη.

sudo sshd -t

💡 Τι περιμένουμε: Αν επιστρέψει χωρίς μήνυμα σφάλματος, η σύνταξη είναι αποδεκτή.

Πρακτική άσκηση

Δοκίμασε τις εντολές σε ένα test Linux σύστημα. Κατέγραψε τι άλλαξε πριν και μετά και κράτησε τις εντολές που αποδείχθηκαν χρήσιμες.

Συνηθισμένα λάθη

  • Εκτέλεση εντολών με sudo χωρίς έλεγχο.
  • Χρήση paths χωρίς να επιβεβαιωθεί ο προορισμός.
  • Αλλαγή ρυθμίσεων χωρίς backup ή τρόπο επαναφοράς.

Checklist

  1. Διάβασε την εντολή πριν την εκτελέσεις.
  2. Έλεγξε το αποτέλεσμα.
  3. Αν κάτι αποτύχει, δες logs και status.
  4. Τεκμηρίωσε τη λύση.
